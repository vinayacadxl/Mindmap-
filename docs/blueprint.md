# **App Name**: MindTask Navigator

## Core Features:

- Task Creation: Create new task nodes and position them on the infinite canvas using drag and drop.
- Task Editing: Edit task properties such as title, description, and status directly on the node.
- Task Linking: Connect task nodes with customizable arrows/lines to represent dependencies.
- Zoomable Canvas: Pan and zoom the canvas for a detailed or bird's-eye view of the entire mind map.
- AI-Powered Suggestion: Utilize an AI tool to suggest logical connections between tasks to generate the map structure automatically. It identifies dependencies, workflows, and subtasks based on entered information.

## Style Guidelines:

- Primary color: Teal (#26A69A) to reflect a sense of focus and clarity.
- Background color: Very light grey (#F5F5F5), nearly white, for a clean, unobtrusive backdrop.
- Accent color: Warm yellow (#FFCA28) to highlight key tasks or calls to action.
- Body and headline font: 'Inter' (sans-serif) for a modern, readable, and neutral appearance.
- Use simple, outline-style icons to represent task categories and actions.
- Employ a clean, minimalist layout that allows the mind map to be the focus.
- Use subtle animations to make the process of dragging elements or editing information more user friendly.
